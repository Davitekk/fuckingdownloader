Public page

Anyone with the URL can use the downloader. Lock it with an access key if randoms start hammering it.

Limits

Keep your server alive. 0 = unlimited where it makes sense. Files are deleted that many minutes after a download finishes, and each visitor only ever sees the downloads made from their own browser.

Network

Proxy applies to every engine (http://, https://, socks5://). The PO token provider helps YouTube stop calling you a bot.

Defaults for new visitors

Cookies

Needed for Instagram stories/private stuff, age-restricted YouTube, YouTube "sign in to confirm you're not a bot", private Reddit, members-only content, etc. Export them from a logged-in browser with an extension like Get cookies.txt LOCALLY (Netscape format) or Cookie-Editor (JSON works too), then paste or upload below. Tip: use a throwaway account. For YouTube, export from a private window you then close, so the cookies don't get rotated.

Spotify (spotdl)

spotdl's built-in API keys are shared by everyone and get rate-limited constantly. Make your own app at developer.spotify.com (free) and paste the keys here. Without keys, Spotify links fall back to the built-in matcher.

Extra arguments

Appended to every command. Power-user stuff, you can break things here.

Custom engines

Plug in any CLI downloader installed in the container. If the URL matches the regex, your command runs first. Placeholders: {url} {outdir} {tmpdir} {cookies} {proxy} {mode} {audio_format} {quality}. Files must end up in {outdir}. No shell: pipes and && won't work, wrap them in a script.

Update engines

Sites change constantly; yt-dlp ships fixes almost daily. If something suddenly breaks, update first. Updates last until the container is recreated (set AUTO_UPDATE=true to update on every start).
